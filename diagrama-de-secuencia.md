Diagrama de secuencia

Registro de un caso de rescate animal

Participantes

- Ciudadano
- Sistema
- Gestor de casos
- Fábrica de expedientes
- Servicio de notificaciones
- Voluntario

Secuencia del proceso

1. El ciudadano envía un reporte de rescate al sistema.
2. El sistema valida la información recibida.
3. El gestor de casos registra el nuevo caso.
4. La fábrica crea el expediente del animal según su especie.
5. El sistema guarda el caso y el expediente.
6. El servicio de notificaciones avisa al voluntario asignado.
7. El voluntario recibe la notificación y atiende el caso.

Resultado

El caso queda registrado y el voluntario recibe la información necesaria para iniciar el rescate.
